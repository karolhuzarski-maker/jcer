O projekcie

Fundament pod statyczną witrynę.

Repozytorium zostało przygotowane jako lekki start dla strony publikowanej bezpośrednio z GitHub Pages. Możesz rozbudować treści, dodać własne grafiki w folderze assets i opublikować stronę z gałęzi głównej.

Publikacja

Jak uruchomić GitHub Pages?

  1. W ustawieniach repozytorium otwórz sekcję Pages.
  2. Jako źródło wybierz gałąź z tymi plikami oraz katalog główny.
  3. Zapisz ustawienia i poczekaj na adres opublikowanej strony.
